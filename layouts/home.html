One field for your whole desktop.

Apps, windows, files, clipboard, calculations, reminders and the web in one ranked list. Opens instantly, runs local by default.

Installed in one command.

Spotlight runs on Omarchy 4 and relies only on tools stock Omarchy already ships. It is listed on the official Omarchy plugin page.

  1. Add the plugin

    Omarchy clones the repository, validates the manifest and enables the plugin in omarchy-shell.

    {{ partial "code.html" (dict "html" (highlight site.Params.installCommand "bash" "")) }}

  2. Press AltSpace

    The shortcut works right after install. It is unbound on stock Omarchy, so Spotlight claims it on first run by writing one marked block to your Hyprland bindings. Prefer a different shortcut? Run the setup tour from Spotlight itself. It changes or undoes the binding at any time.

    If the shortcut does not respond, open Spotlight from a terminal:

    {{ partial "code.html" (dict "html" (highlight (printf "omarchy-shell shell toggle %s '{}'" site.Params.pluginId) "bash" "")) }}

  3. Start typing

    No configuration file is required. When you want one, search for spotlight settings and Spotlight creates it for you.

Type it. Spotlight handles the rest.

Every enabled source searches as you type and the results land in one ranked list. Late file and web results never move the selection you already have. Everything shown here ships today, and more sources and actions are planned.

Name the source when you want to.

Every provider answers by default. A short prefix narrows the list to one of them, and a path searches inside that folder. The search syntax page lists them all.

Switches that show the real state.

System settings appear as switches with their current state read live. Type the name, press Enter, and the switch flips while Spotlight stays open. When a state cannot be read, Spotlight shows no switch rather than guessing.

Time, in your own words.

Describe an event the way you would say it. Spotlight reads the title, the start and the duration, then opens the event in Google Calendar or writes an .ics file for any other calendar. Reminders work the same way: remind me tomorrow at 9 to call the bank.

The web, one keyword away.

Start a query with a bang and Spotlight sends it straight to the site: gh for GitHub, aw for the Arch Wiki, tr to translate. Bare URLs open directly, and web suggestions stay off until you turn them on.
