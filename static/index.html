New in 1.6

Your system,
one colon away.

Type a view name and a colon. Spotlight lists what is on your machine right away and narrows it as you type, like ports:22 or ssh:prod. Enter acts on the row; Shift+Enter copies its endpoint, command, ID or path.

    Everything else

    Type it.
    Spotlight handles the rest.

    Every source searches as you type and lands in one ranked list. Late file and web results never move the row you already picked.

    Switches that show the real state.

    Settings appear with their state read live. Enter flips the switch while Spotlight stays open.

    Numbers, units and money.

    Math, conversions and currency, answered before you finish typing.

    The web, one keyword away.

    Start with a bang: gh, aw, yt. Bare URLs open directly.

    Time, in your own words.

    Say it the way you would say it. Enter adds it to Google Calendar, Shift+Enter writes an .ics file.

    Add Spotlight
    to your Omarchy.

    Runs on Omarchy 4 with the tools it already ships. Free and open source under the MIT license.

    View sourceOmarchy plugin page

    1. 1Add the plugin

      Omarchy clones it, checks the manifest and turns it on.

      omarchy plugin add https://github.com/maajix/omarchy-spotlight.git --enable

    2. 2Press Alt+Space

      The shortcut works right after install. Change it any time in Spotlight Settings.

      AltSpace

    3. 3Start typing

      Nothing to set up first. An app, a file, a sum or a view like ports: all answer here.
