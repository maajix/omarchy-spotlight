Documentation

Everything Spotlight can do, how to install it, and how to make it yours.

Spotlight is a command palette plugin for Omarchy. It runs inside the existing omarchy-shell process, searches your local providers together and ranks the results in one list. These pages cover installation, day-to-day use, the search syntax, the built-in tools and the settings file.
